## [1.0.0] — 2026-10-26

Первая рабочая версия для Android.

### Добавлено

- Список заказов: карточки с моделью, клиентом, статусом, превью проблемы,
  количеством деталей и фото; поиск; фильтры по статусу; счётчики.
- Создание заказа одной кнопкой: запись сразу в базе, открывается карточка.
- Карточка заказа: модель, клиент, контакт, проблема со слов клиента.
- Статусы ремонта: диагностика, в работе, заказана запчасть, готово.
- Чек-лист «Что проверено»: три типовые проверки при создании, подсказки,
  свои пункты, удаление.
- Запчасти: название, количество 1–99, «куплено / не куплено», переименование,
  удаление.
- Заметки по ходу ремонта.
- Фото: съёмка через системную камеру (`FileProvider`), импорт из галереи,
  сетка миниатюр, полноэкранный просмотр, удаление вместе с файлом.
- Удаление заказа с каскадом (чек-лист, запчасти, фото, файлы).
- Автосохранение полей: задержка 250 мс, сохранение при уходе с экрана и
  сворачивании приложения.
- Локальное хранение: SQLite (Room) + файлы в приватном каталоге, без интернета.
- Тема «мастерская»: тёплая бумага, графитовый зелёный, цветовые статусы.

### Проверено

- 6 JVM-тестов и 8 инструментальных тестов на реальном SQLite — успешно.
- Ручные сценарии на TECNO BF7 (Android 12): создание, редактирование, статусы,
  чек-лист, запчасти, заметки, импорт фото, удаление, поиск и фильтры.
- Подпись release-APK проверена `apksigner`.

### Известные ограничения

- Только Android; iOS-версии нет.
- Камера на тестовом устройстве без рабочего превью: запуск камеры проверен,
  запись снимка покрыта тестом на сгенерированном JPEG.
- Нет синхронизации, резервного копирования и экспорта.
- Нет архива заказов и напоминаний.
- Подписи к фото хранятся в схеме, но не редактируются в интерфейсе.
